# Roadmap

## v1.0 — запущено

- Калькулятор контракта: 10 слотов, wear, флоат, EV, ROI, шанс на плюс.
- Контракты дня: автоматический поиск по 94 коллекциям.
- StatTrak и два режима цен (Steam / минимальные листинги).
- Шаринг расчёта через URL, OG-превью, Telegram-кнопка.
- Ежедневное обновление цен через GitHub Actions.

## Дальше — по влиянию на трафик и доход

1. **Партнёрские ссылки.** Вставить код в `assets/config.js` (см. `MONETIZATION.md`).
2. **Свой домен.** Нужен для доверия, AdSense и нормальных превью. ~$10/год.
3. **Страницы коллекций.** 94 статических страницы вида `/collections/dead-hand`:
   список скинов, лучшие контракты, ссылка в калькулятор. Это длинный хвост SEO.
4. **Telegram-бот «контракт дня».** Читает `data/deals.json`, публикует карточку с расчётом
   и ссылкой. Автоматический канал = повторяющийся трафик.
5. **Фильтры и сохранения.** Сортировка по ROI/цене, фильтр по бюджету, сохранённые контракты
   в localStorage, экспорт CSV.
6. **EN-версия.** Отдельный `/en/` с hreflang: западный трафик дороже, конкуренция выше.
7. **Больше механик.** Расчёт кейсов, крафтов, sticker-комбинаций — та же аудитория.

## Что не делать

- Не обещать гарантированную прибыль.
- Не добавлять казино и сомнительные партнёрки.
- Не покупать трафик до появления органики и понятной конверсии.
